# 圖片 AI 超解析

重新啟動 LocalMuse、重新整理頁面後，在生成圖片下方選擇尺寸並按「AI 超解析」。適用既有文生圖、圖生圖結果。

- **2×**：寬、高各放大兩倍。
- **4K**：長邊 3840，保持原比例。例如 16:9 → 3840×2160；正方形 → 3840×3840。
- 使用本機 `models/generation/upscale/RealESRGAN_x2plus.pth` 與專案內 PyTorch 環境；不需其他服務。模型不存在時會回報錯誤，不會自動下載。
- GPU 使用 128 像素區塊、32 像素重疊；完整圖片保留在系統記憶體。CUDA 計算顯存不足會改以 CPU 重試（較慢）。未有 CUDA 時使用 CPU。
- 使用 ×2 模型重複放大到足夠尺寸，再以 Lanczos 調整至目標。因此是超解析輸出，不是原生 4K 生成；細節可能被改寫或過度平滑，尤其文字與臉部。
- 原圖不覆寫。超解析 PNG 與 metadata 分開存於聊天資料庫 `image_upscales`，刪除對話時連動刪除。同一張圖、同一尺寸再次點擊會重用結果。
- 一次一張、最多 30 分鐘；原圖上限 4,194,304 像素，已達 4K 長邊的圖不再套用 4K 模式。執行時請勿關閉網站服務，盡量避免同時生成其他作品。
